# Pixel Date Invite 💗

A responsive HTML/CSS/JavaScript recreation inspired by the pink pixel-art dating invitation shown in the reference Reel.

## Run in VS Code

1. Extract/open this folder in VS Code.
2. Open `index.html` in a browser.
3. For the best development experience, install the **Live Server** extension in VS Code and choose **Open with Live Server**.

## Project structure

```text
date-invite-website/
├── index.html
├── README.md
├── assets/
│   └── pixel-cat.svg
├── css/
│   └── style.css
└── js/
    └── script.js
```

## Customize

Open `js/script.js` to change the interaction/messages.

Open `css/style.css` to change colors, sizing, shadows and animations.

Replace `assets/pixel-cat.svg` with your own pixel-art image if desired.
